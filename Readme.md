# Code Review Project using Google Gemini AI

## Overview

The **Code Review** project is an AI-powered application that utilizes Google Gemini AI for reviewing and analyzing code. The project consists of a **React.js** frontend and a **Node.js/Express.js** backend that interacts with Google AI for intelligent code review.

## Technologies Used

- **Client:** React.js
- **Server:** Node.js / Express.js / Google Gemini AI

## Setup and Installation

### Clone the Repository

```sh
git clone https://github.com/shivrajkhetri7/AI_code_reviewer.git
cd AI_code_reviewer
```

### Environment Variables

Create a `.env` file in the root directory and add the following:

```
API_KEY=your_google_gemini_api_key
PORT=your_desired_port
```

### Install Dependencies

#### Client Setup

```sh
cd client
npm install
```

#### Server Setup

```sh
cd server
npm install
```

## Running the Application

### Start the Client

```sh
npm start
```

### Start the Server

```sh
npm run start:dev
```

## Features

- AI-powered code review and suggestions
- Integration with Google Gemini AI for analysis
- User-friendly interface using React.js
- Scalable backend with Express.js
